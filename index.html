Database Configuration

Seamless support for both SQLite and MySQL

SQLite Active

The app is currently using lightweight SQLite (zero setup required). All records are stored locally in lost_and_found.db.

How to Switch to MySQL (Optional):

  1. Start your MySQL server (via XAMPP, WampServer, or standalone MySQL).
  2. Create a database named lost_and_found in phpMyAdmin or MySQL client.
  3. In app.py, set DB_TYPE = "mysql" (or launch with DB_TYPE=mysql python app.py).
  4. Restart the app! It will automatically connect and create all tables for you.
